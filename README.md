# Выборы в Кольчугино, 2011

Сайт с итогами выборов в Совет народных депутатов Кольчугинского района IV созыва (13 марта 2011 года): результаты партийных списков, явка и голоса по каждому из 40 участков, итоги по восьми округам.

- `index.html` — готовый сайт, один файл, открывается в браузере без сервера.
- `data/` — CSV-выгрузка протоколов с сайта ЦИК (из `kolchugino_2011_CAPTURE_for_ChatGPT.zip`).
- `scripts/build.py` — собирает `index.html` из `scripts/template.html` и данных, попутно сверяя суммы по участкам с итогами ТИК.

Пересборка: `python3 scripts/build.py`
